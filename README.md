🗺️ Mapa de Predicción con Streamlit
Este proyecto permite visualizar predicciones de precios de viviendas segun localizacion geográfica en un mapa interactivo utilizando Streamlit y Folium. Es ideal para mostrar resultados de modelos de machine learning aplicados a datos espaciales.

🚀 Características
Visualización de datos geográficos con mapas interactivos
Interfaz web sencilla con Streamlit
Integración con modelos de predicción personalizados
Uso de streamlit-folium para renderizar mapas dinámicos
📦 Requisitos
Python 3.8 o superior
Entorno virtual (recomendado)
Paquetes listados en requirements.txt
